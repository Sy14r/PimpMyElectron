# Quick triage prototype (local, not released)

The macOS cached preview accepts pointer input and provides Mark read, Reply and Inbox. A host-issued preview gets a short lease while the helper reports the pointer inside the card. Leaving both badge and card expires it. Changing mode, notification scope, unread state or losing the helper invalidates it. The lease also pauses pill collapse; leaving starts the configured idle period again.

Reply opens a compact, 460 × 660 Slack-owned window. The custom header identifies the recipient/workspace. Slack's original conversation or thread pane provides the scrollable history and composer, using the same embedding as the inbox detail view. No editor cloning, custom send API, draft copying or credential extraction is involved. Close/Escape preserves Slack's draft. Open inbox continues in the full triage conversation.

Mark read immediately dismisses the hover preview and optimistically removes that destination from the pill/menu count. The pill gets a paint opportunity before starting native navigation, so mounting Slack’s conversation cannot hold up visual dismissal. The native conversation opens internally with its pane invisible, without enlarging or focusing the Slack window. Its verified unread-banner button is invoked when available, and the observer waits for explicit unread=false. Failure or cancellation restores the item. Newer activity is not covered by the temporary host suppression. Raw observed unread state is never overwritten; the optimistic state is memory-only and bounded. This does not enable the separate conversations.mark adapter. Native navigation can make ordinary requests Slack needs to open a conversation; passive previews themselves make no additional Slack requests. The dedicated banner action is currently qualified for conversations, not threads; thread read confirmation remains dependent on Slack's own navigation behavior.

Auto-close after sending observes an explicit native send attempt and a successful response to a matching chat.postMessage request. Workspace, channel, thread and attempt must match. If the native request omits its workspace, the response must explicitly identify the matching workspace. Failure, scheduling, expired attempts, unrelated traffic or missing evidence leaves the card open. The renderer additionally requires an empty editor, disabled send button and no newer draft input. The acknowledged message must be visibly rendered in native history for 1.1 seconds before closing. Trusted beforeinput detects new typing without mistaking Slack clearing its old draft for user input. On acknowledgement, the renderer immediately suppresses that pill item through the sent timestamp; the host does the same for its count. This does not wait for the periodic snapshot. The native unread control is invoked before the card closes. Suppression expires after 25 seconds if Slack has not confirmed read, and newer activity remains eligible immediately. Response bodies are not stored or logged. This adds response observation only, not API calls.

Live qualification still required: pointer crossing in both dock directions, native composer layout including popovers/attachments, read confirmation for DM and thread, successful send vs failure/scheduling, and work across two workspaces. Tests verify expiry, wrong-target rejection and draft protection; tests alone do not qualify a particular Slack build's native UI.

A live native Mark unread / background Mark read round trip in haxx cleared the unread state while the window remained 44 pixels wide. Compact native DM history and its composer were visually verified. A labeled native reply in haxx was acknowledged, appeared in native history with Sent status, and automatically returned to cluster mode. Scrolling the compact history reached the beginning of the DM. Labeled test replies were sent only in the authorized haxx test workspace.

The empty-pill inbox icon click was blocked by Slack's draggable title region. Explicit `-webkit-app-region:no-drag` on custom surfaces fixes it; verified by clicking the actual icon into the inbox.
