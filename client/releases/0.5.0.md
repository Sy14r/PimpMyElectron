# PimpMyElectron Client 0.5.0

- Daily update checks, Check for Updates in the application menu and About PME, and user-requested download, installation and relaunch through Sparkle.
- Signed update archives, release notes and public feed. Installing requires stopping PME mods and quitting managed host sessions first; settings and launch shortcuts are preserved.
- The repository and releases are now public. No GitHub sign-in is needed for downloads.
- Spotify lists have a thin scrollbar that fades after scrolling stops, plus untinted 32-point edge blur indicating more content. Each blur disappears at its respective list boundary.

Install this version manually if upgrading from 0.4.0 or earlier. Future releases can be installed inside PME. Automatic checks run while the manager runs; shortcut-only sessions do not perform their own checks. Updates do not install unattended.

Apple Silicon, macOS 13.3 or later. Slack and Spotify are installed separately.
