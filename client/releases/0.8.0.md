# PimpMyElectron 0.8.0

## New Slack mod: Quote in Reply

- Enable **Quote in Reply** in PME’s Slack mod list to add a quotation-mark button to the action bar shown when you hover over a message.
- Quote a message into the current channel, DM, or already-open thread composer without creating a new thread. The quote appears above your existing draft, and nothing is sent automatically.
- Works independently in standard Slack or alongside **Slack Triage**. Running it alone keeps Slack’s ordinary interface and does not start the Triage helper or background message observer.
- Uses Slack’s native blockquote formatting, with Markdown quoting as a plain-text fallback. Preserves line breaks and readable emoji and mention labels; attachments, rich cards, and original inline styling are not copied.
- The mod makes no additional API calls. It edits only the current draft using the clicked message’s rendered text.

## Mod manager

- Added spacing between available mod cards to make apps with multiple mods easier to browse.
- When Slack is running with Quote in Reply alone, the manager offers **Open Slack** and hides the Triage settings action.

## Install or update

Use **Check for Updates** in PME, or download the ZIP below. Stop managed app sessions before updating, then relaunch them through PME. Quote in Reply is optional: enable it before launching Slack. For an existing shortcut, use **Update selection** to include the new mod.

Requires Apple Silicon and macOS 13.3 or later. Slack integration was tested with the official direct-download Slack 4.52.162 client and depends on Slack’s private UI interfaces.
