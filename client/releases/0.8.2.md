# PimpMyElectron 0.8.2

## More reliable Slack search navigation

- Fixed a case where selecting a person in Slack’s Command-K search opened their DM but left triage showing “Loading conversation.” PME now recognizes the existing DM when Slack finishes loading its cached recipient information, without requiring a second search.
- Fixed a second navigation race where expanding the inbox could remove the search popup before the selected result was opened. The accepted selection now survives long enough to recover through Slack’s native navigation.
- Recipient and workspace checks remain in place. These fixes add no API calls or background polling and preserve existing drafts.

## Explore PME

The [product website](https://sy14r.github.io/PimpMyElectron/) now includes a Slack Triage walkthrough and dedicated pages for all four bundled Slack and Spotify mods.

## Validation and compatibility

The navigation failures were reproduced in automated regression tests. Live confirmation of these specific cases is still pending; Slack’s private interfaces can vary across client versions.

## Install or update

Choose **Check for Updates** in PME, or download the ZIP below. If prompted, use **Stop sessions and update**, then relaunch your mods through PME or a saved shortcut. When updating from 0.8.0 or earlier, stop mod sessions manually first.

Requires Apple Silicon and macOS 13.3 or later.
