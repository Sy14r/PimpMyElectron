First standalone PimpMyElectron client for Apple Silicon Macs running macOS 13.3 or later.

- Native macOS window with a dark mod-manager interface and the new orbital PME icon.
- Discovers official Slack installations, shows bundled mods, and saves your selection.
- Launches Slack Triage in everyday mode using a private debugging pipe, with background API polling disabled.
- Bundles Node and the native menu-bar controller: no Terminal, Node installation, compiler, or source checkout needed to run.
- Imports settings and existing PME integration-profile ownership from a source checkout on the same Mac.
- Developer ID signed, Apple notarized, and stapled. Includes SHA-256 checksums and a source/version manifest.

Download the ZIP, extract it, and move **PimpMyElectron.app** into Applications. Quit any running Slack session before launching Slack through PME. For source users, choose **Import existing setup** and select your PME project folder. Otherwise, sign into the separate PME-launched Slack profile once.

Slack itself is not bundled. This release supports Apple Silicon only; updates are installed manually. Slack integration uses private client interfaces and may need updates when Slack changes. Repository access is required to download this private release.
