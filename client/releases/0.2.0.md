Launch shortcuts for your saved mod selections.

- Create **Slack — PME.app** in Applications and launch it from Finder, Spotlight, or the Dock without opening the mod manager.
- Each shortcut remembers its Slack installation and mod selection independently of the manager.
- Reopening a matching session brings it forward; other Slack sessions are never stopped automatically.
- Reveal, rename, update the saved selection, or remove shortcuts in PME.
- Small signed launcher apps reuse the installed PME runtime. Keep PME installed; no Node installation is needed.

Requires Apple Silicon and macOS 13.3+. Restart a session launched with client 0.1.0 before using selection matching. Profiles and sign-ins stay on this Mac. Updating PME updates the mod implementations used by existing shortcuts.
