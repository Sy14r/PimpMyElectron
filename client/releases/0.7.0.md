# PimpMyElectron 0.7.0

## Slack keyboard shortcuts

- Open a dedicated keyboard cheat sheet from Slack Triage’s menu-bar icon or with **Command + Shift + Comma**. Its global shortcut is configurable in Settings.
- The scrollable sheet matches Settings, with the same colors, typography, and key badges. It stays visible when switching apps, and includes a button to jump to shortcut settings.
- Press Escape, or the sheet’s shortcut while it is focused, to close it and return focus to your previous app.
- Press **1** in the inbox to jump to the first unstarred conversation in the current filter. **0** still jumps to the first row. Single-key navigation stays inactive while typing.

## First-time conversations

- Fixed selecting a person through Slack’s **Command + K** switcher when there is no cached DM yet: Slack’s recipient-filled new-message composer now opens beside the triage inbox instead of falling back to the full Slack view.
- If search results change while opening, PME retains the selected recipient or asks you to search again rather than opening a different person or a blank composer.

## Open-source project

- PME’s original source is now licensed under **MPL 2.0**. The app and its bundled helpers include the license and source information; About PME also links to them.
- Refreshed setup, contribution, mod compatibility, and release documentation for public contributors.

## Install or update

Use **Check for Updates** in PME, or download the ZIP below. Quit managed app sessions before updating, then relaunch them through PME to load the updated mods. Requires Apple Silicon and macOS 13.3 or later.
