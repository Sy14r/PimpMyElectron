# PimpMyElectron Client 0.4.0

## Spotify Camera Pause

- New optional mod pauses Spotify when selected applications use the camera, then resumes only playback it paused.
- Works independently of Menu Player, including with ordinary Spotify. Enable either mod or both; launch shortcuts preserve that selection.
- Dedicated camera menu-bar icon and PME settings entry when running alone. With Menu Player enabled, its settings gear also opens Camera Pause settings.
- Choose watched applications with recognizable app icons and configure a 0–30 second resume delay.
- Manual playback changes, lost camera detection, sleep, and restarts cancel pending resume. “Keep Spotify paused” explicitly cancels auto-resume.

Camera detection uses local macOS diagnostic attribution, verified on macOS 26.6.2. Availability can vary across macOS versions and managed devices. It does not record camera or microphone content; Spotify control uses macOS Automation permission.

## Mod compatibility

- Mods declare macOS, Windows, Linux, or global compatibility, including dependency checks.
- PME shows compatible mods by default. “Show incompatible” reveals other mods with an explanation; incompatible selections cannot launch.
- The current client and bundled mods remain macOS-only.

## Validation and installation

Camera Pause was tested live both with Menu Player and independently, including pause, delayed resume, and standalone settings. Automated coverage includes playback ownership, delayed pause confirmation, settings migration, platform filtering, and standalone launch behavior.

Download the Apple Silicon ZIP, extract it, and replace PimpMyElectron.app in Applications. Stop running PME mods and quit PME before replacing the app. Settings are preserved outside the application bundle. Requires macOS 13.3+ and separately installed Slack or Spotify; camera attribution has the compatibility limits described above.
