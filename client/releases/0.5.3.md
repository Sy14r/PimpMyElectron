# PimpMyElectron Client 0.5.3

## Slack Triage

- Inbox filters now stay on a single horizontally scrollable row. Subtle edge fades indicate more filters, mouse-wheel and trackpad scrolling are supported, and H/L keyboard navigation keeps the selected filter visible.
- Added an **Apps & agents** filter for app conversations, including Slackbot. Classification uses Slack’s cached state without extra API calls; muted conversations remain excluded from unread notifications.
- Improved marking app and agent conversations as read from the pill and inbox. Failed native read actions now roll back the pending state instead of appearing successful.
- Fresh launches load Slack **Home** and capture its available cached state before opening the triage inbox. Activity remains parked behind the inbox to avoid marking hidden conversations as read.
- Normal Slack window size and position now survive quitting and relaunching. Saved positions adjust to connected displays when your monitor setup changes.

## PME client

- **About PME** now contains Overview, What’s new, and Feedback tabs, with a title that follows the selected tab and fewer entries in the main sidebar.
- Release notes and version history are bundled with the application and available offline in **About PME → What’s new**.
- **About PME → Feedback** lets you write a bug report or idea, review exactly what will be shared, then copy the report or open a GitHub issue draft. Version details are optional; logs, workspace names, and messages are not collected. GitHub submission remains your choice. Feedback drafts stay intact when switching tabs during the current app session.

Update from **Check for Updates…** in PME, or download the ZIP below. Stop active PME mod sessions before installing, then relaunch them to load the updated mods.

Apple Silicon, macOS 13.3 or later. Slack and Spotify are installed separately.
