# PimpMyElectron 0.6.0

## Feedback without a GitHub account

- Review and send feedback directly from About PME → Feedback. No browser or GitHub account is required.
- Reports are public. PME sends only the report you review, with optional version details.
- Drafts survive reopening PME, and retrying a submission checks the same report instead of creating duplicates.

## Slack triage

- Starred conversations appear in a separate section at the top of the inbox, while respecting your current filter. Threads from starred conversations also appear first.
- Fixed stale unread indicators when Slack clears its live unread entry but still holds older startup data. Reading in Slack now clears the inbox and pill instead of reviving those older counts.
- Clarified the conversation menu’s Notifications & mute entry and themed Slack’s native notification menus. Choose all new posts, just mentions, or mute and hide; More options includes temporary mute choices.

## Install or update

Use Check for Updates in PME, or download the ZIP below. Quit managed app sessions before updating, then relaunch them through PME to load the updated mods.
