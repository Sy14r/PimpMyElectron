# PimpMyElectron 0.9.0

## Private mods from local folders

Teams can now distribute their own Slack mods without putting them in PME’s public repository or rebuilding the client. Your company handles delivering files to a local folder; PME handles installing and launching them.

- Open **Mod sources → Add folder** to register a collection. Adding a folder only reads metadata.
- Review and install a complete version, then enable its mods on the Slack page. New mods start disabled.
- External mods appear alongside bundled mods with their source name, platform compatibility, dependencies, and access description. Saved launch shortcuts support them too.
- Installed copies work offline. Refresh sources to discover changes, review updates before installing, or switch back to the previous version. Updates take effect on the next mod session.
- Private mod names and source paths are excluded from automatic feedback version details.

## External helper support

Slack packages can include renderer JavaScript/CSS, foreground native helpers, or both. Helpers have per-mod storage and are stopped when their owning session ends. Closing the manager still leaves active mod sessions running.

Native helpers must pass Apple Developer ID publisher verification and Gatekeeper checks. PME does not re-sign helpers or bypass macOS protections. Mod files are checksummed before installation and launch. Mods and helpers remain trusted code, not sandboxed extensions; install only from sources whose authors and writers you trust.

An example collection, packaging tool, and authoring guide are included in the source repository: [Local mod sources](https://github.com/Sy14r/PimpMyElectron/blob/client-v0.9.0/docs/MOD-SOURCES.md).

## Initial limits

External package execution currently supports Slack. Bundled Spotify mods continue working normally; external Spotify packages cannot be enabled yet. Helpers requiring Launch Services, elevated privileges, system-service installation, or symlink-based frameworks need additional support. Permission prompts must be validated for each helper on its target Macs.

Removing a source prevents future launches of its mods but does not delete the original folder or cached copies. Revoking access to a company folder does not revoke copies already downloaded. Remote repository fetching and automatic mod updates are not included.

## Install or update

Choose **Check for Updates** in PME, or download the ZIP below. If prompted, use **Stop sessions and update**, then relaunch your mods through PME or a saved shortcut. When updating from 0.8.0 or earlier, stop mod sessions manually first.

Requires Apple Silicon and macOS 13.3 or later.
