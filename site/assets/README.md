# Product visuals

`slack-inbox.png`, `slack-pill.png`, and `slack-strip.png` render the current Slack Triage code with fictional Studio North messages. `mod-manager.png` renders the current manager with synthetic installation data. No account data is used. Regenerate on macOS with `node scripts/site-assets.mjs` (requires Google Chrome). The native conversation illustration on the page is explicitly labeled.
